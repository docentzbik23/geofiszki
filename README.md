# GeoFiszki — wydanie 44 (do publikacji na GitHub Pages)

Aplikacja statyczna PWA do nauki przepisów geologicznych. Baza zawiera **2076 fiszek** oraz **378 pytań ABC**. Archiwum zawiera pliki strony i bibliotekę źródłowych PDF.

## Publikacja na GitHub Pages
1. Rozpakuj całe archiwum.
2. Skopiuj zawartość rozpakowanego folderu (w tym `index.html`, `app.js`, `laws.json`, `questions.json`, `sw.js`, `manifest.webmanifest` oraz folder `pdf/`) do katalogu publikowanego w repozytorium GitHub.
3. W GitHub wybierz **Settings → Pages** i upewnij się, że źródłem publikacji jest właściwa gałąź i katalog (np. `main` / root).
4. Zatwierdź zmiany (commit), a po wdrożeniu odśwież stronę. Przy problemach z poprzednią wersją wykonaj twarde odświeżenie; cache PWA ma w tym wydaniu nową nazwę.

## Zmiany w wydaniu 44
- Przeformułowano 11 pytań, tak by sprawdzały zagadnienie, a nie pamięć numeru artykułu/paragrafu.
- Zachowano wszystkie identyfikatory fiszek, odpowiedzi i podstawy prawne.
- Odświeżono wersję pamięci podręcznej PWA.
- Nie dodawano nowych kart: celem jest przygotowanie strony do publikacji.
